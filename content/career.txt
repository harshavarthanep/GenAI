### Moving abroad: the checklist | I
POINT: Shortlist 3 countries using the ranking above and your own priorities.
POINT: Read the official visa page: salary thresholds, degree recognition, sponsor rules.
POINT: Get your degree evaluated or attested if the country needs it.
POINT: Tailor your resume to local norms (no photo or date of birth in the UK, US, Ireland and Canada).
POINT: Apply to companies that already sponsor visas; search "visa sponsorship" plus your role on the portals.
POINT: Before accepting, compare cost of living, tax, health insurance and notice period, not just salary.

## c-resume | file | Resume that passes ATS and humans | Structure, bullets and examples
### Rules | B
POINT: **One page** for under 8 years of experience; simple single-column layout; standard fonts.
POINT: Use standard headings: Summary, Skills, Experience, Projects, Education, Certifications.
POINT: Save as **PDF** (text-based, not an image). Name the file `Firstname_Lastname_Role.pdf`.
POINT: Mirror keywords from the job description honestly (e.g. "RAG", "LangChain", "vector database").
POINT: No photos, tables, icons or multiple columns for ATS-heavy companies.
---
### The bullet formula | B
S: **Accomplished [X] as measured by [Y] by doing [Z]** (the XYZ formula popularised by Google recruiters).
TABLE: Weak → strong
| Weak | Strong |
| Worked on a chatbot | Built a RAG chatbot over 120 HR documents, reaching 91% answer accuracy on a 50-question test set using hybrid search and reranking |
| Used Python for reports | Automated weekly PMO reporting with Python and an LLM summariser, cutting preparation time from 5 hours to 40 minutes |
| Learned SQL | Wrote 30+ SQL queries with window functions to analyse 1M orders and identify a 12% repeat-purchase opportunity |
---
### Skills section for GenAI roles | I
TABLE: Group your skills
| Group | Examples |
| Languages | Python, SQL, JavaScript (basic) |
| GenAI | Prompt engineering, RAG, embeddings, agents, tool calling, evaluation, fine-tuning (LoRA) |
| Frameworks | LangChain, LangGraph, LlamaIndex, Hugging Face Transformers |
| Data | Pandas, NumPy, PostgreSQL, pgvector, Chroma |
| Deployment | FastAPI, Streamlit, Docker, Git, GitHub Actions |
---
### Common mistakes | B
TABLE: Avoid
| Mistake | Fix |
| Listing tools with no proof | Tie each skill to a project bullet |
| Long paragraphs | 1–2 line bullets starting with a strong verb |
| No links | Add GitHub, portfolio and live demo links |
| Fake or inflated claims | Interviewers will ask; keep it true and specific |
| Same resume for every job | Tailor the summary and top bullets for each role |

## c-jobs | briefcase | Finding and applying for jobs | Where to search, how to apply, how to follow up
### Where to search (free) | B
TABLE: Global job platforms
| Platform | Coverage | Notes |
| LinkedIn Jobs | Global | Filter "past week", set alerts, search "visa sponsorship" |
| Indeed | 60+ countries | Wide coverage, salary estimates |
| Company career pages | Global | Many roles never reach job boards |
| Wellfound | Global startups | Salary ranges shown, many remote roles |
| Remote boards | Worldwide | We Work Remotely, Remote OK, Remotive, Himalayas |
| Hacker News "Who is hiring" | Global / remote | Monthly thread with direct contacts |
| Country portals | Per country | See the country ranking for each country's best portals |
---
### The weekly application system | B
FLOW: Pick 10 target roles > Tailor resume summary + 3 bullets > Find a referrer or hiring manager > Apply + send short note > Track in a sheet > Follow up after 7 days
TIP: Referrals and direct messages to hiring managers convert far better than cold online applications. Aim for quality: 10 tailored applications beat 100 generic ones.
---

### Offer basics | I
POINT: Research ranges on free sites such as Glassdoor, AmbitionBox (India) and Levels.fyi before discussing numbers.
POINT: Let the company share a range first when possible; negotiate on total compensation (base, bonus, equity, benefits, learning budget).
