## r-practice | terminal | Where to practise every subject | Two options for everything: install locally or use free online tools
### Python | B
ROW: Local (Windows / Mac / Linux) :: Install from python.org (tick "Add to PATH"), then VS Code with the Python extension
ROW: Online (no install) :: This app's Python Lab, Google Colab, Kaggle Notebooks, Programiz online compiler, Python Tutor (visualise code)
### SQL | B
ROW: Local :: SQLite + DB Browser for SQLite, or PostgreSQL
ROW: Online :: This app's SQL Lab, SQLBolt, SQLite Online, DB Fiddle, LeetCode SQL problems
### Data analysis and ML | B
ROW: Local :: Python + Jupyter (`pip install notebook pandas scikit-learn`)
ROW: Online :: Google Colab, Kaggle Notebooks (free GPU quotas)
### LLM APIs and prompting | I
ROW: Local :: Ollama or LM Studio with open models (free, runs on your laptop)
ROW: Online :: Google AI Studio (free tier, rate-limited), Hugging Face Spaces, this app's Prompt Lab
### Embeddings, vector DBs and RAG | I
ROW: Local :: Chroma, FAISS or Qdrant (open source) + sentence-transformers
ROW: Online :: This app's RAG Lab (runs in your browser), Google Colab
### Fine-tuning | A
ROW: Local :: Needs a GPU; use Unsloth or Hugging Face TRL
ROW: Online :: Google Colab or Kaggle free GPUs with small models (0.5B–3B)
### Deployment | I
ROW: Local :: Docker Desktop (free for personal use), FastAPI, Streamlit
ROW: Online :: GitHub Pages (static sites), Hugging Face Spaces, Streamlit Community Cloud
